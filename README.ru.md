<p align="center"><a href="README.md">English</a> · <b>Русский</b></p>

Долгосрочная цель: находить на странице речевые пузыри, распознавать в них текст и переводить или озвучивать его, всё без сервера.

> **Статус:** ранняя разработка. Идёт работа над версией 0.1. Консольный прототип уже открывает папку с изображениями и читает все страницы. Следующий шаг это окно на Qt.

## Архитектура

Ядро написано как библиотека на C++23 без UI и без зависимостей от платформы. Каждая платформа получает поверх него свой нативный интерфейс.

```
Desktop (Qt 6)   Android (Kotlin)   iOS (Swift)   Web (JS)
      │                └───────────────┼──────────────┘
      │                        слой биндингов
      └────────────────┬───────────────┘
                   C++ ядро
```

Первым появится десктопное приложение. Мобильные и веб-клиенты появятся, когда в ядре будут реальные возможности.

## План версий

| Версия | Цель |
|---|---|
| 0.1 | Открыть папку с изображениями и листать страницы в окне на десктопе |
| 0.2 | Находить речевые пузыри классическим компьютерным зрением (OpenCV) |
| 0.3 | Распознавать текст внутри пузырей (OCR) |
| 0.4 | Переводить или озвучивать распознанный текст |

## Технологии

- C++23, CMake
- Qt 6 для десктопного интерфейса
- OpenCV для обработки изображений (с версии 0.2)
- ONNX Runtime для локального ML-инференса (когда понадобится)
- GoogleTest для unit-тестов

## Сборка

Нужны CMake 3.20 или новее и компилятор с поддержкой C++23, включая `std::expected`: Clang 16+, GCC 12+ или Apple Clang из Xcode 15+.

```sh
./build.sh
```

Скрипт настраивает проект в папку `build/` и компилирует его. Те же два шага можно выполнить вручную:

```sh
cmake -S . -B build
cmake --build build
```

## Запуск

Текущая версия это консольный прототип. Передайте ему папку со страницами манги:

```sh
./build/apps/desktop/fukiyomi путь/к/главе
```

Программа находит в папке изображения (PNG, JPEG, WebP, по порядку имён файлов), читает каждое и печатает его размер:

```
version 0.1.0
Page count: 2
	Size page 0: 217572 bytes
	Size page 1: 277086 bytes
```

Коды возврата: `0`, если прочитаны все страницы, `1`, если папку не удалось открыть, `2`, если часть страниц не прочиталась.
